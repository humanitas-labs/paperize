## Context

The v0.1 multiply fill reliably warms white pages while preserving the original
PDF structure. Real-book review exposed a missing visual cue from naturally
aged paper: the page center should remain slightly brighter than the perimeter.

Both effects must continue to work on born-digital and scanned PDFs without
rasterizing pages.

## Changes

1. Extend presets with a vignette edge color and strength.
2. Add an elliptical radial paper shading with exact default endpoints:
   `#FAEDDB` at the center and `#FFE6C3` at the perimeter.
3. Hold the center color flat until the outer portion of the page and vary the
   transition boundary subtly and deterministically by page.
4. Leave original text and ink colors unchanged.
5. Add a `--vignette` override. Strength zero remains a fully neutral boundary.
6. Add generated rendering tests for preserved dark marks, exact paper colors,
   and deterministic page variation.
7. Bump the package to v0.2.0, update docs and the changelog, regenerate the two
   real-book outputs, then publish the repository publicly.

- Strict mypy passes.
- All tests pass with at least 85% branch-aware coverage.
- Strength zero renders identically to the source.
- A solid black test mark retains its source color.

## Actual

  perimeter) with a PDF-native elliptical shading.
- Delayed the vignette transition to the outer 26–38% of the normalized radius
  and added deterministic per-page extent variation.
- Preserved original text and ink colors.
- Added the vignette CLI override while preserving the neutral strength-zero
  boundary.
- Passed 27 tests at 92.45% branch-aware coverage plus Ruff and strict mypy.
- Rendered the repository README to a two-page PDF with `ppdf`, paperized it,
  and visually inspected both pages for preserved black text, a broad flat
