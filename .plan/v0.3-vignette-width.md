## Context

The existing `--vignette` option controls edge-color intensity, but readers
cannot control how far the transition extends toward the page center. The
default width is too present on some clean born-digital pages.

## Changes

1. Add a preset-level vignette-width default of `0.32`.
2. Add `--vignette-width <0..1>` and pass it through validated configuration.
3. Interpret width as the fraction of normalized center-to-edge radius occupied
   by the transition. Smaller values keep it closer to the edge.
4. Scale deterministic per-page variation to 20% of the selected width.
5. Treat width zero as a uniform center paper color with no edge transition.
6. Update tests, README, changelog, tool documentation, and package version.
7. Regenerate the Manifesto reader copy with width `0.12` and inspect it.

## Verification

- CLI range validation and option propagation pass.
- A narrower width moves the transition boundary outward.
- Per-page width variation remains deterministic and bounded.
- Width zero removes the transition without changing source ink.
- Ruff, strict mypy, tests, coverage, package build, and installed CLI smoke
  test pass.
- The regenerated Manifesto has a broad flat center and no visible gradient
  boundary.

## Actual

- Added `--vignette-width` with a preset default of `0.32`; `0.12` confines the
  transition to a narrow outer band.
- Retained deterministic page variation at 20% of the selected width.
- Replaced the stitched shading function with concentric radial geometry after
  visual QA exposed Poppler clipping at narrow widths.
- Added a regression test for the cross-viewer-safe shading structure.
- Passed 30 tests at 92.56% branch-aware coverage plus Ruff, strict mypy, and
  package builds.
- Regenerated the 68-page Manifesto at width `0.12`; Poppler renders of pages
  1, 14, and 50 were clean, and extracted text remained byte-for-byte
  equivalent.
